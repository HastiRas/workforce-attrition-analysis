# Workforce Attrition Analysis

An exploratory People Analytics project examining employee attrition patterns using Python, pandas, and matplotlib.

## Project Overview

This project analyzes the IBM HR Analytics Employee Attrition & Performance dataset, containing 1,470 synthetic employee records.

The goal is to explore how employee attrition varies across departments, overtime status, and job satisfaction levels, and to identify patterns that could inform HR decision-making.

## Tools & Technologies

- Python
- pandas
- matplotlib
- Google Colab / Jupyter Notebook

## Key Findings

- **Overall attrition:** 16.12% of employee records were marked as having left.
- **Department differences:** Sales had the highest attrition percentage (20.63%).
- **Overtime:** Employees working overtime had a 30.53% attrition percentage, compared with 10.44% among employees without overtime.
- **Job satisfaction:** Employees with the lowest satisfaction had a 22.84% attrition percentage, compared with 11.33% among those with the highest satisfaction.

## Business Recommendations

- Investigate workload and overtime patterns to better understand employee departures.
- Examine department-specific factors associated with higher attrition.
- Monitor employee satisfaction through surveys and feedback.

## Dataset

[IBM HR Analytics Employee Attrition & Performance — Kaggle](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)

The dataset is synthetic and does not represent actual employee records.

## Limitations

This project uses descriptive analysis. The relationships observed do not establish causation, and the findings should not be treated as evidence about a real company's workforce.

3. Download the CSV dataset from the Kaggle link above.
